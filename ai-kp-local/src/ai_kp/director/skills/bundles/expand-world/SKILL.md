# Expand World

Use the supplied deterministic world-gap analysis as a prerequisite, not as permission to write
state.

## Workflow

1. Confirm that existing visible module content and World Fact heads do not already answer the
   intent.
2. Preserve module Canon, active spoiler boundaries, required anchors, current geography, and
   previously confirmed facts.
3. Propose the smallest plausible addition that serves the player's stated need. Consider era,
   region, settlement scale, institutions, travel, law, economy, and current disruptions.
4. Record assumptions, confidence, possible conflicts, source basis, and at least two alternatives.
5. Prefer ordinary environmental additions over key NPCs, truth-changing revelations, or anchor
   shortcuts. Mark higher-impact candidates for stricter review.

## Safety Boundaries

- Never assume that every settlement contains the same modern facility or service.
- Never present a generated candidate as pre-existing confirmed fact.
- Never alter original module chunks, Canon, anchors, maps, NPCs, memories, or World Facts.
- Do not use a weak-model guess as default evidence. If basis is insufficient, return a specific
  clarification or conflict instead of a plausible-sounding invention.
- Produce a candidate only. Player confirmation or KP approval and materialization remain external.
